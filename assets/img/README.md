# Kit de logomarca — fin-stack academy

## Arquivos vetoriais

- `fin-stack-symbol-light.svg`: símbolo colorido para fundos claros.
- `fin-stack-symbol-dark.svg`: símbolo colorido para fundos escuros.
- `fin-stack-symbol-black.svg`: símbolo monocromático preto.
- `fin-stack-symbol-white.svg`: símbolo monocromático branco.
- `fin-stack-horizontal-light.svg`: assinatura horizontal para fundos claros.
- `fin-stack-horizontal-dark.svg`: assinatura horizontal para fundos escuros.
- `fin-stack-stacked-light.svg`: assinatura vertical para fundos claros.
- `fin-stack-stacked-dark.svg`: assinatura vertical para fundos escuros.

## Uso

Preserve uma área livre equivalente à largura do corpo vertical do “F” em todos os lados. Não altere proporções, espaçamento, cores ou alinhamento. Use a versão `dark` sobre preto e fundos escuros; use a versão `light` sobre branco e fundos claros. As versões monocromáticas são reservadas para impressão em uma cor ou contextos sem suporte à paleta principal.

Os PNGs do símbolo incluem transparência e são fornecidos em 16, 32, 64, 128, 256 e 512px. As assinaturas PNG têm fundo transparente e resolução adequada para apresentações e documentos.
